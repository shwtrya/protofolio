# Project Proof Assets

Place the original project proof photos/screenshots in this folder with these exact names:

- `smart-home-proses.jpg`
- `smart-home-hasil.jpg`
- `instalasi-isp-proses.jpg`
- `instalasi-isp-hasil.jpg`

The portfolio includes an honest fallback panel if these JPG files are not available yet, so the project cards and case study gallery will not show broken images while documentation is still being prepared.

`src/data/projects.ts` currently references these assets as 1200 x 800 images. If the final files use different dimensions, update the `width` and `height` values in `src/data/projects.ts`.
